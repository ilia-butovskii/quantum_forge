# Инструкция по запуску

## База знаний

В `scraper` необзодимо установить зависимости  и запустить `python main.py`

После исполянения скрипта в директории появится директория `knowledge_base`, ее необходимо перенести в директорию `ai`

## Запуск

Необходимо создать в корне проекта файл .env (см .env.example для примера)

При первом запуске необходимо выставить `INIT_DATABASE=true` для создания и наполнения индекса

После этого необходимо запустить `docker-compose up`

После того, как база инициализируется (см логи), для использования бота необходимо запустить `run_ai_cli.sh`
